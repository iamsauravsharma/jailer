Expand description

Run a closure inside a EnvJailer environment.

This function creates a EnvJailer, runs the provided closure, and ensures the jail is closed afterward.

§Errors

Returns any error from creating or closing the EnvJailer, or from the closure itself.

§Example

use jailer::with_env_jailer;
unsafe {
    with_env_jailer(|env_jailer| {
        // Do something in the jailed directory
        std::env::set_var("JAILED_ONLY_KEY", "VALUE");
        env_jailer.set_preserved_env("SOME_KEY");
        Ok(())
    })
    .unwrap();
}

// Variables set inside the jail are reverted on close
assert!(std::env::var("JAILED_ONLY_KEY").is_err());

§Safety

This function calls std::env::remove_var and std::env::set_var, which are unsafe due to possible data races in concurrent contexts.
