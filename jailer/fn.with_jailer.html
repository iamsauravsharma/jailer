Expand description

Run a closure inside a Jailer environment.

This function creates a Jailer, runs the provided closure, and ensures the jail is closed afterward.

§Errors

Returns any error from creating or closing the Jailer, or from the closure itself.

§Example

use jailer::with_jailer;

with_jailer(|_jailer| {
    // Do something in the jailed directory
    Ok(())
})
.unwrap();
